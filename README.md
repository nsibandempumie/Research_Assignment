## Sections Covered

### Section A: Data Fundamentals (Q1 — Q10)
Covers core data concepts including databases, data warehouses, data lakes,
data marts, structured vs unstructured data, data modeling, data mining,
DBMS platforms, ETL processes, and common data storage formats.

### Section B: Artificial Intelligence & Machine Learning (Q11 — Q18)
Covers AI fundamentals, machine learning types, deep learning, neural networks,
NLP, large language models, generative AI, training datasets, and computer vision.

### Section C: APIs, Tools & Developer Concepts (Q19 — Q28)
Covers APIs, API keys, REST APIs, JSON, prompt engineering, the MAP function,
cloud computing, version control with Git, Jupyter Notebooks, and Python libraries.

### Section D: Data Ethics, Governance & Careers (Q29 — Q34)
Covers data privacy, GDPR, data ethics, data governance, AI bias,
data career roles, and business intelligence tools.

### Section E: Personal Reflection (Q35 — Q37)
Personal reflections on the most interesting and challenging concepts,
and thoughts on how data and AI will impact my future career.
